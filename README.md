<details>
<summary><b>04 · ARP Poisoning / MITM — Ettercap + Wireshark</b></summary>

Topology: Kali attacker · Windows 7 victim · Windows 10 victim — isolated host-only network

Baseline

Recorded IPv4 + MAC information for both Windows hosts and Kali

Verified clean ARP state and baseline reachability

Attack

Performed host discovery with Ettercap

Configured Win7 and Win10 as the two targets

Enabled IP forwarding on Kali

Launched the ARP poisoning MITM attack

Validation

Confirmed poisoned ARP mappings on both victims

Captured traffic on Kali with Wireshark

Generated ICMP traffic and observed it transiting through the attacker

Security takeaway: demonstrates the mechanics of Layer 2 MITM and the detection opportunity around anomalous ARP mappings and traffic paths.

</details>

<details>
<summary><b>05 · Network Forensics — Malware Delivery + C2 Investigation</b></summary>

Victim requested /update.exe four times over HTTP:8000

Outbound TCP:4444 connection to C2 host

Approximately 566 KB transferred in under one second after handshake

Approximately 67-second sustained bidirectional session

Identified delivery, staging, and C2 beacon phases from PCAP analysis

</details>
