## This is me :)

Hi, I'm Haider — a SOC Analyst on the way up, currently CEH certified out of Corvit, based in Lahore. I build detection pipelines and then try to break them myself first, because you can't write a good Sigma rule for an attack you've never actually run.

- 🛡️ Built a home Wazuh + Sysmon SOC lab and tuned it from **200 → 12 alerts/day** without losing true-positive coverage
- 🕵️ Wrote a custom Sigma rule to close a LOLBin detection gap the default SIEM baseline missed
- 📋 Documented 3 full incident-response cases end-to-end: simulate → detect → MITRE ATT&CK map → escalate → remediate
- 🌐 Correlated raw PCAPs against SIEM alerts to validate detections and pull real IOCs
- 🔎 Turned OSINT recon into a risk-prioritized exposure report, not just a list of findings
- 📡 Also comfortable on the other side of the fence — Metasploitable2 exploitation, ARP/MITM labs — because understanding the attack is what makes the detection mean something
